# StageSmith Editor (SSE)

**StageSmith Editor**（ステージ職人）は、Windows環境に移植されたファミコン風2Dアクションゲームのステージマップを、視覚的に構築するためのマップエディタです。

タイル単位でのマップ編集、ページ間の接続・スクロール設定、敵などのオブジェクト配置（ゲーム側の敵定義に合わせたカラーパターン表示に対応）、ブックマークやタグによる作業補助機能などを備え、ゲーム実行用のバイナリ（`.bin`）およびステージ定義データ（`.def`）を出力します。

出力データは、コンパニオンアプリケーション **mm2hack**（C++製ゲームアプリ）で読み込まれます。

---

## 動作環境

| 項目 | 内容 |
|---|---|
| OS | **Windows 11 x64 専用** |
| 追加インストール | 不要（自己完結型ビルドのため .NET ランタイムの別途インストール不要） |

> **Windows 10 環境での動作は保証していません。** Windows 10 のサポート終了に伴い、本ツールは Windows 11 のみを対象としています。

## インストール方法

1. [Releases](../../releases) ページから最新の `StageSmithEditor_vX.X.X_win-x64.zip` をダウンロード
2. 任意のフォルダに解凍
3. `StageSmithEditor.exe` を実行

インストーラーは不要です。フォルダごと配置すればそのまま動作します。

### 新しいバージョンへの更新

1. 新しいバージョンの zip を、**別の新しいフォルダ**に解凍
2. 以前の設定を引き継ぐ場合は、旧フォルダの `SSE_Config.ini`（エディタ設定）と `SSE_Layout.xml`（ウィンドウ配置）を新しいフォルダへコピー

プロジェクト・ステージファイルはエディタのフォルダとは別に保存されるため、そのまま新しいバージョンで開けます。

### 初回起動時の警告について

配布ファイルは未署名のため、初回起動時に Windows SmartScreen の警告が表示される場合があります。
その場合は「詳細情報」→「実行」を選択してください。

## 使い方

1. `File > New Project` で新規プロジェクトを作成
2. `File > New Stage` でステージを追加
3. タイルパレットからタイルを選択し、マップビュー上に配置
4. Object Palette（Ctrl+F9）に敵の画像シートとテンプレートを登録し、オブジェクトツール（O）で敵やプレイヤー開始位置を配置
5. `File > Export BIN` でゲーム実行用データ（`.bin` と `.def`）を出力

詳しい操作方法は、エディタ内で **F1キー** を押すか、以下のヘルプサイトを参照してください。

📖 [StageSmith Editor ヘルプドキュメント](https://www.loopunlimited-rootone.com/40000/sse.help/ja/index.html)

## ファイル構成

| ファイル | 用途 |
|---|---|
| `.sseproj` | エディタ専用プロジェクトファイル（正規データ） |
| `.ssestage` | ステージ単位のエディタデータ |
| `.bin` | ゲーム実行用マップバイナリ（Export BIN 時に `.def` と同時に出力） |
| `.def` | ステージ構造・オブジェクト配置などのロジック定義（JSON形式） |
| `SSE_Config.ini` | エディタ設定（exe と同じフォルダに自動作成） |
| `SSE_Layout.xml` | ウィンドウ配置（exe と同じフォルダに自動作成） |

ファイルの詳しい仕様は、ヘルプの「インターフェースファイル仕様」を参照してください。

## 関連プロジェクト

- **mm2hack** — 本エディタが出力する `.bin` / `.def` データを読み込むC++製ゲームアプリケーション
  - オブジェクト配置（`.def` の `entities` / `stage.start`）を反映するには、これらに対応した版の mm2hack が必要です
  - 敵のカラーパターン表示には、mm2hack の敵定義（`assets/data/enemies`）と NES パレット（`assets/system/nes_palette.txt`）を参照します
